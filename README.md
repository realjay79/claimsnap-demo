# ClaimSnap

Roof claim files adjusters don't send back. ClaimSnap guides roofing crews through every required shot, checks the claim file before it goes out, and emails a clean, slope-by-slope package to the assigned adjuster.

- Landing page: https://realjay79.github.io/claimsnap-demo/
- Clickable demo: https://realjay79.github.io/claimsnap-demo/demo/

## What's here

| Path | What it is |
| --- | --- |
| `index.html` | Landing page: pitch, how it works, comparison, features, pricing, FAQ |
| `demo/index.html` | Clickable 16-screen demo, one claim from sign-up to depreciation release |
| `assets/` | App screenshots used on the landing page |

All names, addresses and claim numbers are sample data. Prices are proposed launch pricing.

## Hosting

Static files served by GitHub Pages from the `main` branch, root folder. No build step.
